Privacidad y seguridad

Última actualización: 23 de noviembre de 2026

Tándem es una aplicación de escritorio desarrollada por Cristian Pareja. Esta política explica qué datos maneja la aplicación.

En resumen: Tándem no recopila datos sobre ti. Todo lo que genera se queda en tu equipo.

Datos que recopila el desarrollador

Ninguno. Tándem no tiene cuentas de usuario, analítica, telemetría ni publicidad, y no envía al desarrollador información sobre ti, tus proyectos o tu uso de la aplicación.

Datos que se guardan en tu equipo

La aplicación guarda localmente, en la carpeta .tandem de tu usuario:

  • su configuración y preferencias;
  • el historial de tus sesiones de trabajo;
  • un identificador de instalación generado al azar, que no se transmite a ningún lugar.

Estos datos permanecen en tu equipo y puedes borrarlos cuando quieras eliminando esa carpeta.

Servicios de terceros

Tándem funciona como interfaz de herramientas que tú instalas y configuras:

  • Claude Code (Anthropic) y Codex (OpenAI). El contenido que envías a estos asistentes, incluidos tus mensajes y los archivos de proyecto que ellos lean, lo procesan esos proveedores según sus propias políticas de privacidad. Tándem no lee ni almacena las credenciales de esas herramientas.
  • API de Anthropic (opcional). Si configuras una clave de API, se guarda solo en tu equipo y únicamente se envía a Anthropic para autenticar tus solicitudes.
  • Git y servicios de repositorios. Las operaciones de Git (fetch, push, etc.) se conectan a los servidores que tú tengas configurados en tus repositorios.
  • Control remoto de Claude Code (opcional). Si lo enciendes en una sesión, Claude Code la conecta a claude.ai para que puedas seguirla desde el navegador o la app móvil de Claude, según las condiciones de Anthropic. Se apaga cuando tú lo indicas o al cerrar la sesión.

Conexiones del desarrollador

La aplicación consulta periódicamente información de servicio publicada por el desarrollador y alojada en GitHub. Esa consulta no incluye datos personales ni identificadores. Como en cualquier solicitud web, GitHub puede registrar datos técnicos como la dirección IP, según su propia política de privacidad.

Actualizaciones

Tándem revisa al abrirse, y cada pocas horas, si hay una versión nueva en las publicaciones públicas del proyecto en GitHub. Esa consulta descarga un archivo con el número de la versión más reciente y no envía datos personales ni identificadores.

  • Nunca se actualiza sin tu permiso: te avisa y tú decides cuándo instalar.
  • Cada actualización está firmada digitalmente por el desarrollador. Tándem comprueba la firma antes de instalar y descarta cualquier archivo que no coincida.
  • En Windows, el instalador recomendado instala Tándem solo para tu usuario, así que las actualizaciones no necesitan permisos de administrador.
  • La versión de la Microsoft Store no usa este mecanismo: la actualiza la propia Store.

Seguridad

  • Tándem no lee, guarda ni transmite las credenciales de Claude Code ni de Codex. El inicio de sesión lo hacen esas herramientas.
  • Los cambios que propone un agente se aplican según el modo que elijas (preguntar, aceptar ediciones, plan o automático) y las reglas de permisos de cada herramienta.
  • La vista previa de archivos HTML se muestra aislada: la página no puede acceder a la aplicación ni a otros archivos fuera de su carpeta.
  • La configuración de tus servidores MCP, que puede contener tokens, nunca se muestra en la interfaz.

Si encuentras un problema de seguridad, escríbenos al correo de contacto.

Menores de edad

Tándem es una herramienta para desarrolladores y no está dirigida a menores de 13 años.

Cambios

Si esta política cambia, se publicará la versión actualizada en esta misma página.

Privacy and security

Last updated: November 23, 2026

Tándem is a desktop application developed by Cristian Pareja. This policy explains what data the application handles.

In short: Tándem does not collect data about you. Everything it creates stays on your computer.

Data collected by the developer

None. Tándem has no user accounts, analytics, telemetry or advertising, and it does not send the developer any information about you, your projects or how you use the application.

Data stored on your computer

The application stores locally, in your user's .tandem folder:

  • its settings and preferences;
  • the history of your work sessions;
  • a randomly generated installation identifier, which is never transmitted anywhere.

This data stays on your computer and you can delete it at any time by removing that folder.

Third-party services

Tándem is an interface for tools that you install and configure yourself:

  • Claude Code (Anthropic) and Codex (OpenAI). Content you send to these assistants, including your messages and any project files they read, is processed by those providers under their own privacy policies. Tándem does not read or store the credentials of those tools.
  • Anthropic API (optional). If you configure an API key, it is stored only on your computer and is sent only to Anthropic to authenticate your requests.
  • Git and repository services. Git operations (fetch, push, etc.) connect to the servers configured in your repositories.
  • Claude Code Remote Control (optional). If you turn it on for a session, Claude Code connects it to claude.ai so you can follow it from the browser or the Claude mobile app, under Anthropic's terms. It turns off when you say so or when the session closes.

Connections to the developer

The application periodically checks service information published by the developer and hosted on GitHub. That request contains no personal data or identifiers. As with any web request, GitHub may log technical data such as the IP address, under its own privacy policy.

Updates

When it opens, and every few hours, Tándem checks the project's public releases on GitHub for a new version. That request downloads a file with the latest version number and sends no personal data or identifiers.

  • It never updates without your permission: it lets you know and you decide when to install.
  • Every update is digitally signed by the developer. Tándem verifies the signature before installing and discards any file that doesn't match.
  • On Windows, the recommended installer installs Tándem for your user only, so updates don't need administrator rights.
  • The Microsoft Store version doesn't use this mechanism: the Store updates it.

Security

  • Tándem doesn't read, store or transmit Claude Code or Codex credentials. Those tools handle sign-in themselves.
  • Changes proposed by an agent are applied according to the mode you choose (ask, accept edits, plan or automatic) and each tool's permission rules.
  • HTML file previews are isolated: the page can't access the application or files outside its own folder.
  • Your MCP server configuration, which may contain tokens, is never shown in the interface.

If you find a security issue, please write to the contact email.

Children

Tándem is a tool for developers and is not directed at children under 13.

Changes

If this policy changes, the updated version will be published on this same page.
